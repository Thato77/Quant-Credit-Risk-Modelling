# Quant-Credit-Risk-Modelling
End-to-end quantitative credit risk modelling using SQL, Python, machine learning, model validation and IFRS 9-style ECL analysis.

##1. Project Overview

The project builds an end-to-end quantitative credit risk model for residential mortgages, using Freddie Mac's publicly available Data. It is designed to demonstrate practical application in credit risk modelling, data engineering, and regulatory-aligned analysis informed by Basel II/III & IFRS 9 cocepts, while remaining manageble, well scoped portfolio project.
